# Human Trial Checklist

Use this checklist for a short manual trial.

- Launch succeeds with `start_prompt_launcher.bat`.
- Launch succeeds with `start_prompt_launcher.ps1` or `python prompt_launcher.py` if needed.
- Project selection works.
- Workflow selection updates after project selection.
- Situation selection updates after workflow selection.
- Skill details update after situation selection.
- Prompt preview updates.
- Copy button copies the full prompt.
- Pasted prompt includes `【Prompt Launcher Guard】`, `Project`, `Target`, and `Skill`.
- Pasted prompt does not include Situation, Description, Safety notes, or Post-copy checklist.
- Pasted prompt goes to the correct Codex, GPT, or Human notes target.
- Labels are clear enough to choose without guessing.
- Missing Skills can be identified and written down.
- Prompt does not request auto-paste, auto-send, browser automation, external API calls, deletion, automatic commit, or automatic backup.
